# README: Coursera Getting and Cleaning Data Course Project
**By D. Werner**

This repository was created with the purpose of showcasing the 
course project for "Getting and Cleaning Data" week 4.  

The purpose of this project was to demonstrate my ability to collect, 
work with, and clean a data set. The goal is to prepare tidy data that can be
used for later analysis.  

### The project and repository includes

- A README file (this file) that explains how the script works and how they are connected.
- A codebook (CodeBook.md) that describes the variables, the data, and any transformations or work performed to clean up the data.
- A file (run_analysis.R) that can be run as long as the Samsung data is in the R working directory.


### How the script works and how they are connected
The script is available as a file named "run_analysis.R". This script is the full script.  
Both in the .R file and in the CodeBook.md are the steps taken to clean the data explained.
